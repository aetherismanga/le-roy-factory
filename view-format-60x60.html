Vérifier les dimensions et la finition avant de choisir

Les familles de formats facilitent la découverte. Pour une commande ou une pose, comparez les dimensions de chaque référence, les joints et les indications fabricant. Un format proche ne remplace pas un format exact dans le calcul des quantités. Les données de commande et les configurateurs conservent leurs propres dimensions précises.
